# 자료와 문항 구조 검수

시험지 지면 양식과 문항 구조는 별개다. 공식 문항과의 대조는 자료가 제공하는 관계, 학생이 수행하는 추론, 발문이 지시하는 대상, 선택지의 판단 방식으로 한다. 같은 주제나 같은 문항 번호만으로 구조가 같다고 판정하지 않는다.

각 문항에 대하여 다음 근거를 남긴다.

1. 입력 문항 해시, 검수한 학생 PDF 해시, 공식 자료의 PDF 해시·쪽·문항 번호.
2. 공식 문항과 제작 문항 각각의 자료 역할, 필요한 개념·추론, 발문 대상, 선지 논리.
3. 원문 수치·단위·관계·방향·범례와 실제 도판의 대응. 도판이 추가하거나 생략한 사실 및 정답 단서 유무.
4. 일치하는 구조와 남은 차이. 대응 근거가 없으면 미확인으로 기록한다.
5. 표시·편집 수정으로 해결할 부분과 원고의 발문·선택지·평가 개념 재검토가 필요한 부분.

문장 카드(schematic)는 본문을 이미지로 렌더링하는 방식이다. 이를 지도·경로망·연표의 구현 또는 검증으로 세지 않는다. 표·사료·대화·일반 본문도 정당한 자료이므로 모든 문항에 그림이나 `<보기>`를 추가하지 않는다. 도식에 학생이 구해야 할 계산 결과나 정답 경로를 추가해서는 안 된다.

파일 해시 검사, 원문 누락 검사, 페이지 검수, 봉인 성공은 위 문항 구조 대조의 대체 증거가 아니다. `verification.json`이나 반환 ZIP을 근거로 평가원 구조 동등성을 주장하지 않는다. 문항별 근거를 갖춘 검수가 끝나기 전에는 구조 검수 완료로 표시하지 않는다.

## M04 v4의 공간·연결 자료

원문 해시에 결합한 네 전용 렌더러를 추가했다. 새 판본에 자동 재사용하지 않는다.

- 9번: 기존 다섯 무방향 연결만 그린다. 개선안의 연결이나 장애 회피 경로는 추가하지 않는다.
- 12번: 서·동 강변과 기존 신고소를 배치한다. 두 시점에 관한 나머지 조건은 원문에 남긴다.
- 13번: 거주 도시와 이용 시설 사이의 네 이용량을 그린다. 정산 금액이나 합계는 추가하지 않는다.
- 23번: 서·동 구역, 제작 위치와 현재 보관 위치를 구분한다. 제작 장소를 제작자의 국적으로 바꾸어 표시하지 않는다.

9·13·23번의 원문 조건은 보존하고 관계도를 추가한다. 12번은 배치만 기술한 한 줄을 관계도로 치환한다. 이는 표시 문제의 수정이며, 25문항 전체의 구조 동등성이나 출고 승인을 뜻하지 않는다. 기타 문장 카드와 원고 차원의 구조 차이는 후속 검수 대상이다.
