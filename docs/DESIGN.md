# 통합사회 Press v0.1 설계

목표: FRG-SOC-2028-M01의 승인된 25문항을 내용 보존 우선으로 편집 가능한 2단 HWPX, 한글에서 실제 변환한 PDF, 별도 정답·해설과 검증 반환 묶음으로 제작한다. 최종 출고 승인은 사람에게 남긴다.

공식 2025 예시 PDF 6쪽을 모두 관찰했다. A3 세로(842×1191 pt), 본문 좌우 약 31 mm 여백, 중앙 세로선, 좌단→우단 순서이다. 첫 쪽 큰 제목과 이후 작은 머리말, 하단 중앙 쪽수, 흑백 표·도판, 길이에 따른 문항 간 간격을 참고한다. 이는 관찰한 형식이며 미래 확정 규정이 아니다. 표제는 ‘2028 통합사회 연습 문제’와 ‘편집 검토 초안’을 사용한다.

선택: 새 소규모 Python 어댑터 + 네이티브 HWPX 문단·표 + 한글 COM 실제 PDF 변환. 기존 과학 Press 전체 복제는 불필요하며, 페이지 전체 이미지 HWPX는 편집성 요구를 충족하지 못한다. NAS 양식은 로컬 복사본만 실제 렌더/분석하며 과거 내용·바탕쪽·이미지를 가져오지 않는다. HWPX 스킬의 기존 두 쪽 문제집 편집 절차는 이 신규 시험지 제작과 달라 적용하지 않고, 원본 보존 및 실제 렌더 검증 원칙을 따른다.

경계: Forge 읽기 전용 callable로 승인·현재 해시·visual handoff를 재검증한다. 기존 science 1.1의 통합사회 미지원 상태는 변경하지 않는다. 새 계약은 로컬 초안이며 공식 Forge export를 우회하여 승인된 것처럼 표시하지 않는다. item_version이 없는 원문에는 canonical SHA를 content-addressed revision으로 사용하고 별도 사람 버전을 만들지 않는다.

자료: 모든 학생 조건을 순서대로 보존하고 Markdown 표는 네이티브 셀로 변환한다. 지도·통계·연표 요청은 원문과 필수 관계를 보존하는 명세·실제 SVG/PNG로 반환한다. 좌표 없는 지도는 도식으로만 표현하며 지리·비례를 추정하지 않는다. 정답과 해설은 별도 출력 경로만 가진다.

배치: A3, 2단, 읽을 수 있는 본문 크기부터 시작한다. 2문항 파일럿 후 25문항에 확장한다. 문항을 단위로 배치하고 분할을 피하며 6쪽은 목표이지 강제 상한이 아니다. 원문이 길어 초과하면 수치를 보고한다.

검증: 결함 주입(누락 선택지/도판, 변조 도판, stale 원문), 25개 번호/순서, canonical 입력 결합, 학생 출력 누출, 네이티브 구조, 실제 HWPX 재열기와 PDF 변환, 전체 페이지 이미지 검토, 도판 값·관계 검토, 파일 SHA 반환. 해시 검증과 의미/사람 승인을 구분한다.
