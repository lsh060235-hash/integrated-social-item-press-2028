## 증적과 범위

- 현재 정본으로 375개 검토 패킷과 51개 handoff를 재구성해 원본과 대조했다.
- 학생 27쪽·교사 17쪽 전체를 실제 이미지로 검토했다. 문항별 공식 예시 대조 75개는 가장 가까운 주제/형식 비교이며 완전 동일성을 뜻하지 않는다.
- 해설 75문항과 오답 설명 300개를 두 차례 원문 대조했다. M03 교집합 설명 문구를 수정 후 재검토했다.
- 현재 기온 기준과 음수 글꼴, 지도 점선 범례, 본문이 참조하는 원본 표를 보존했다. M03 마지막 해설 분할을 감지해 배분 다단을 해제하고 실제 재렌더했다.
- M03 최종 학생 변경쪽 1·6을 다시 보았고 나머지 6쪽의 픽셀 동일성을 확인했다. 해설 7쪽도 전쪽 검토한 수정 시험본과 픽셀 동일하며 각 해설이 한 단 안에 완결된다.
- 세 반환 묶음의 파일 SHA와 ZIP CRC를 확인했다. 각 묶음은 실행 당시 코드·Forge 소스·입력 원본을 보존한다.
- 분할된 PDF를 허용하던 회귀 테스트가 먼저 실패하는 것을 확인하고 검사와 재렌더 경로를 추가했다. 전체 통합 테스트 104개, 기본 테스트 51개 통과(로컬 입력 의존 10개 제외).
