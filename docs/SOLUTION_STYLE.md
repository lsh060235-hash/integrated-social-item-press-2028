# 해설 서술 기준 v0.3

사용자가 요청한 EBSi 평가원 기출 해설의 어투·서술 방식을 분석하여 Press의 해설 교정에 적용한다. **평가원이 출제한 문제에 대한 EBSi 해설**을 참고한 것이며, 평가원의 공식 해설·EBS 인증·문장 복제를 뜻하지 않는다.

## 참고 자료와 범위

2026-09-08 EBSi 기출문제 메뉴의 2025년 6월 고3 모평(평가원) 해설 링크에서 직접 받은 PDF다. 모두 **2026학년도 6월 모의평가**에 해당한다. 네 파일의 문항별 구성을 확인하고, 앞부분의 개념·관점형 및 경제의 계산·표 해설을 중심으로 서술과 지면을 대조했다. 전수 문장 통계나 EBS 전체 해설의 규칙으로 일반화하지 않는다.

## 관찰 결과와 적용

| 요소 | 참고 해설의 관찰 | Press 적용 |
|---|---|---|
| 문항 제목 | 번호 뒤에 이해·비교·분석의 대상을 밝힌다. | 단순 정답 번호 대신 짧은 주제 제목을 붙인다. |
| 정답 설명 | 대상·개념을 먼저 식별한 후 판단 근거를 연결한다. 자료 해석이 별도 표제가 아니라 정답 설명 안에 포함되기도 한다. | `정답 해설`에서 자료 해석과 판단을 연결한다. 모든 문항에 별도의 자료 해설 단락을 강제하지 않는다. |
| 어투 | `~이다`, `~한다`, `~볼 수 없다`의 평서문을 사용한다. | 학생에게 풀이를 지시하는 문장이나 내부 작업 기록을 설명문으로 고친다. |
| 오답 | 번호 또는 보기 기호 뒤에 해당 진술의 잘못된 부분을 바로잡는다. 같은 근거의 선지는 묶기도 한다. | 이번 두 회차는 복합 진술형 선지가 많아 오답 네 개를 각각 설명한다. 맞는 부분과 틀린 부분을 구별한다. |
| 계산 | 비교 대상·비용 범주·단위를 밝히고 필요에 따라 식이나 표로 정리한다. | 분모, 시간 구간, 단위와 지원 상한을 명시한다. 복잡한 계산과 최종 판단은 문단을 나눈다. |
| 서술 범위 | 제시된 자료의 대상과 조건에 맞추어 판단한다. | 관찰과 인과, 비율과 인원, 가상 규칙과 실제 법령, 후보 선별과 역사적 확정을 구별한다. |

출력은 첫머리 정답표, 문항 주제와 정답, 정답 해설, 오답피하기 순이다. 본문은 기존 편집 가능한 HWPX와 A3 2단 지면을 유지한다. 한글의 배분 다단을 사용하여 마지막 쪽도 양쪽 단에 나누되 문항 해설 묶음은 유지한다. 이번 요청의 적용 범위는 **어투와 서술 구조**이며 EBSi의 A4 1단 판형을 복제하지 않는다. 기관 로고는 사용하지 않는다.

## 교정 원칙

1. 정답 번호·학생용 조건·선지는 변경하지 않는다. 원본 교사용 근거도 `input-packet.json`에 남긴다.
2. 내부 영문 코드와 자료 ID를 인쇄하지 않는다. 지문의 명칭·시점·장소로 풀어 쓴다.
3. 같은 근거를 정답 요약과 풀이 단계에서 반복하지 않는다. 필요한 계산·예외·추론 한계는 생략하지 않는다.
4. 오답의 잘못된 결론뿐 아니라 그 선지가 사용한 계산 기준이나 논리의 오류를 바로잡는다. 다른 선지의 오류를 잘못 설명하지 않도록 대조한다.
5. 가상 입장을 특정 사상가의 실제 주장으로 바꾸거나, 가상 보호 규칙을 실제 법정 기준으로 표현하지 않는다.
6. 교정본은 초안이며 기존 내용·교육과정 검토의 보류를 해소하지 않는다.

## 교정본 입력과 재현

`--solution-overlay`를 생략하면 종전 원문 해설을 출력한다. 지정하면 아래 구조의 별도 교정본을 적용한다. 정확히 같은 회차·판본·문항 원문 해시에만 적용할 수 있으며 모든 문항과 각 문항의 오답 네 개가 필요하다. 공개 예시는 합성 문장이다.

```json
{
  "schema_version": "press-solutions-editorial-v0.1",
  "campaign_id": "FRG-SOC-2028-M01",
  "source_version": "원본 판본",
  "source_items_sha256": "원문 전체 canonical SHA-256",
  "items": [{
    "number": 1,
    "source_item_sha256": "해당 원문 문항 canonical SHA-256",
    "answer": 2,
    "topic": "자료의 해석",
    "explanation": ["비교 대상은 같은 집단이다. 두 시점의 값을 비교하면 증가한 것을 알 수 있다."],
    "wrong_answers": [
      {"choice": 1, "text": "비교하는 시점이 다르다."},
      {"choice": 3, "text": "분모는 전체 집단의 인원이다."},
      {"choice": 4, "text": "관찰된 증가만으로 원인을 확정할 수 없다."},
      {"choice": 5, "text": "다른 집단에 관한 자료는 제시되지 않았다."}
    ]
  }]
}
```

build는 원본을 변형하지 않고 교사용 출력 사본에만 교정문을 붙인다. 적용한 JSON을 `solution-editorial.json`으로 출력에 보존하고 SHA-256을 `verification.json`에 기록한다. seal은 교정본 변경 여부, 원문과의 연결, 정답·오답 번호와 PDF의 교정문 누락을 다시 검사한다. 자동 검사는 논리적 동치나 좋은 문체를 보증하지 않으므로 문항별 원문 대조 및 최종 PDF 전쪽 검토가 필요하다.

```powershell
python -X utf8 press_revision.py build --archive 'C:/input/review.zip' --solution-overlay 'C:/input/solution-editorial.json' --out work/edited-001
```
